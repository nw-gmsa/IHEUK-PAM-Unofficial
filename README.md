# IHE UK Patient Administration Management (Unofficial)

An unofficial IHE UK national extension of IHE ITI [Patient Administration Management (PAM)](https://profiles.ihe.net/ITI/TF/Volume1/ch-14.html) and [Patient Identifier Cross-referencing (PIX)](https://profiles.ihe.net/ITI/TF/Volume1/ch-5.html).

Initial content is derived from the HSCIC ITK HL7 v2 Message Specifications (v1.0.15) and Reference Tables (v1.0.14) - see `Specifications/HSCIC` - updated from HL7 v2.4 to **HL7 v2.5.1** and mapped to HL7 FHIR R4 profiles based on [HL7 Europe Base](https://hl7.eu/fhir/base/) and UK Core terminology.

Build with `./_build.sh build` (SUSHI + HL7 IG Publisher). See [Guidance for FHIR IG Creation](https://build.fhir.org/ig/FHIR/ig-guidance/index.html).
